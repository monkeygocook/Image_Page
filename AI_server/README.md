# AI Server Setup Guide (กันลืม)

### 🚀 วิธีการรันระบบ
1. ติดตั้งไลบรารีทั้งหมด (ต้องรันตอนต่อเน็ต):
   pip install -r requirements.txt

2. สั่งรันเซิร์ฟเวอร์ FastAPI:
   python -m uvicorn main:app --reload

### ⚠️ โน้ตสำคัญสำหรับระบบ (สถาปัตยกรรม AI)
- มีไฟล์ `patch.py` อยู่ที่หัวแอปเพื่อดักจับปัญหาเวอร์ชัน NumPy 2.x (Monkey Patching `np.long`) ห้ามลบเด็ดขาด
- โหมด `cleaner` (object) จะใช้โมเดล LaMa AI ในการรัน ครั้งแรกที่กด Execute ระบบจะดาวน์โหลดไฟล์ `big-lama.pt` (196MB) มาเก็บไว้ในเครื่องโดยอัตโนมัติ


### สิ่งที่ต้องทำต่อหลังจาก Funtion ใช้งานได้ครบแล้ว
- การจัดการข้อผิดพลาด
1. บอกวิทย์ให้เพิ่ม ดักขนาดและนามสกุลไฟล์ เช่น ผู้ใช้ upload file ที่เป็นประเภท pdf หรือ txt หรือไฟล์ขนาดใหญ่เกิน 50 MB ระบบจะต้องแจ้งเตือนกลับไปอย่างสุภาพด้วย
2. ดักภาพที่ไม่มี Mask ซึ่งอันนี้ทำเรียบร้อยแล้ว

- การทำความสะอาดทรัพยากร
Lama จะกินหน่วยความจำเครื่องค่อนข้างสูงดังนั้นต้องมีการเครียร์ Cache ไฟล์ภาพเก่าๆในโฟรเดอร์ output ไปใส่ไว้ในจุดประมวลผลเสร็จ AIserver จะได้ไม่ล่ม

- การทำเอกสารกำกับระบบ
• เขียนไฟล์ requirements.txt: เพื่อให้เพื่อนพิมพ์ pip install -r requirements.txt แล้วติดตั้งไลบรารีทุกตัว (รวมถึงตัวพิเศษอย่าง simple-lama-inpainting และ patch.py ที่เราแต่งเพิ่มเข้าไป) ได้ในคำสั่งเดียวโดยไม่ติดปัญหาเวอร์ชันตีกัน
• อธิบายสเปกเครื่องที่จำเป็น: ระบุว่า AI Server นี้จำเป็นต้องใช้ Python เวอร์ชันไหน และกินพื้นที่ในการเก็บโมเดล big-lama.pt เท่าไหร่
